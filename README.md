## SQL Exploratory Data Analysis (EDA) Project

This project was inspired by the data analysis project from Data with Baraa, which I used as a reference for the dataset and overall project context.

I independently wrote the SQL queries. The analysis and SQL scripts reflect my own implementation and approach.

## What I Learned 🤔

During the creation of this project, some parts were familiar, especially the first six scripts, ince I had already practiced similar concepts before. However, the later scripts were more challenging because they required me to look beyond the query itself and think about what the data was actually telling me. 

One of the biggest takeaways was realizing that SQL is not just for application development. It can also be a powerful tool for investigation, troubleshooting, and Root Cause Analysis (RCA).
